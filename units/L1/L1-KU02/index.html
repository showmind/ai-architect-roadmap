L1-KU02 · SOLID 原则

面向对象设计的五大基本原则 — 点击卡片展开详解

S

单一职责原则 (SRP)

Single Responsibility Principle

▼

定义：一个类应该只有一个引起它变化的原因。

核心思想

每个模块、类或函数只负责一项职责。如果一个实体承担了多个职责，那么当其中一个职责发生变化时，可能会影响其他职责的正常运作。

反例

// ❌ 既处理数据又处理报告
class Employee {
  calculatePay() { /* 财务逻辑 */ }
  saveToDatabase() { /* 持久化逻辑 */ }
  generateReport() { /* 报表逻辑 */ }
}

正例

// ✅ 职责分离
class PayCalculator { calculatePay() {} }
class EmployeeRepository { save() {} }
class ReportGenerator { generate() {} }

识别信号

God Class过长方法过多依赖

O

开闭原则 (OCP)

Open/Closed Principle

▼

定义：软件实体应对扩展开放，对修改关闭。

核心思想

通过抽象和多态机制，在不修改已有代码的前提下增加新功能。新增行为通过添加新代码实现，而非修改运行良好的旧代码。

实现方式

抽象基类 + 具体实现、策略模式、插件架构。

示例

// ✅ 新增折扣策略只需添加类，无需修改原有代码
interface DiscountStrategy {
  calculate(price);
}
class VipDiscount implements DiscountStrategy { ... }
class StudentDiscount implements DiscountStrategy { ... } // 新增

价值

降低回归风险提升可维护性

L

里氏替换原则 (LSP)

Liskov Substitution Principle

▼

定义：子类型必须能够替换其基类型，且程序行为不变。

核心思想

继承必须确保超类所拥有的性质在子类中仍然成立。子类可以扩展父类的功能，但不能改变父类原有的功能。

经典反例

// ❌ 正方形继承长方形
class Rectangle { setWidth(w); setHeight(h); }
class Square extends Rectangle {
  setWidth(w) { this.w = w; this.h = w; } // 违反 LSP
}

正确做法

// ✅ 抽象 Shape，各自实现
abstract class Shape { abstract area(); }
class Rectangle extends Shape { ... }
class Square extends Shape { ... }

检查清单

强化前置条件弱化后置条件抛出意外异常

I

接口隔离原则 (ISP)

Interface Segregation Principle

▼

定义：不应强迫客户端依赖它不使用的接口。

核心思想

将臃肿的接口拆分为更小、更具体的接口，让客户端只需了解它们实际需要的方法。

反例

// ❌ 胖接口
interface Animal {
  eat(); fly(); swim();
}
class Dog implements Animal {
  fly() { /* 狗不会飞！ */ }
}

正例

// ✅ 接口细分
interface Eatable { eat(); }
interface Flyable { fly(); }
interface Swimmable { swim(); }
class Dog implements Eatable, Swimmable { ... }

实践要点

接口最小化角色分离

D

依赖反转原则 (DIP)

Dependency Inversion Principle

▼

定义：高层模块不应依赖低层模块，两者都应依赖抽象。

核心思想

细节应依赖抽象，而非抽象依赖细节。通过依赖注入(DI)和控制反转(IoC)实现解耦。

反例

// ❌ 直接依赖具体实现
class OrderService {
  private dao = new MySQLDao(); // 换数据库就崩
}

正例

// ✅ 依赖接口，注入实现
class OrderService {
  constructor(private dao: DataDao) {}
}
// 使用时注入
new OrderService(new MongoDao());

配套模式

依赖注入控制反转容器服务定位器
